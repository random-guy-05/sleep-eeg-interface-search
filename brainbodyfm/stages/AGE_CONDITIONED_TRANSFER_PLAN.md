# STAGES age-conditioned transfer analysis

Plan dated October 27, 2026. Added after the original continuous STAGES analyses.
This document and its code are to be committed before any STAGES rank endpoint
is computed. It is a prospective freeze of an additional analysis of existing
data, not preregistration of the original study. The original prespecified
executive-function search-gap endpoint and all earlier results remain unchanged.
The execution receipt records the actual commit and file digests. No OSF
registration has been completed at the time this file was prepared.

## Rationale and primary endpoint

Evaluate the fixed signed Stable4 score by age-conditioned AUROC, the metric for
which it was developed, without fitting a STAGES cognition link. The endpoint
is the pooled proportion of same-center case/noncase pairs with absolute age
difference <=2 years in which the case has the higher risk score. Ties contribute
one half. Cases have an adjusted executive-plus-memory composite <=-1.0 SD.
All four center families contribute eligible pairs; this is pair weighting, not
an average of center AUROCs. The primary result must appear in the abstract
whatever its direction, once it can be computed with the specified score.

The primary hypothesis is AUROC >0.5, assessed using a two-sided percentile 95%
bootstrap interval. A lower bound above 0.5 supports discrimination in the
specified direction. Age matching within a two-year window does **not** make
an age-only score exactly 0.5 by construction. The pairing rule is retained;
that mathematical claim is not used.

## Score definition and provenance gate

Four heads, in this order:

1. `pred_regression_f_total_power_rem_rel_theta`, +0.360
2. `pred_regression_f_fs_chirp_c4m1`, +0.270
3. `pred_regression_f_sigma-9-std`, -0.235
4. `pred_regression_f_sigma_bandpower_kurtosis_c_n1`, -0.135

Higher values indicate higher predicted impairment risk. The submitted code
orients heads by [+1,+1,-1,-1], standardizes those oriented heads using source
population means and SDs, then applies positive weight magnitudes
[0.360,0.270,0.235,0.135]. Its appended sex coefficient is zero. No sign flip,
coefficient refitting, head substitution, or threshold search is permitted.

The primary normalization must come from the **original organizer-trained
artifact for submission 2593**, or an auditable export with artifact SHA256,
head order, directions, weights, source means/scales, and deployment recipe.
Neither the 338-person development cache nor STAGES moments can substitute for
those original source scales. Shifts in the source means cancel in pairwise
ranks; unknown relative source SDs can change the ranking. A saved generic Phi
or SleepFM checkpoint is not the trained downstream Stable4 artifact.

The accessible submission repository has evolved to gated date blends and
other profiles. The selected deployment branch for the organizer-scored entry
must be verified before describing its official scores as measurements of
standalone Stable4. The signed four-head recipe can be evaluated separately
when its original source moments are recovered; finding a newer recipe is not
permission to replace the fixed score.

**Current disposition at freeze:** original trained normalization absent from
local/Drive searches and the accessible GitHub search. Consequently the primary
endpoint is unavailable, rather than evaluated with replacement scales. The
default CLI refuses execution without that artifact. `--available-only` is an
explicit partial run and cannot produce the primary estimate. Recovery of the
artifact requires a provenance review and the realized-design power stage
before unlocking the primary CLI; any code change must be committed before
the primary result is examined. No inference of the missing scales from STAGES
outcomes or scores is allowed.

Comparator risk is the negated published brain-health score (higher published
BHS denotes better brain health). The normalization sensitivity applies the
same signed weights after label-free within-center STAGES standardization.
Within-center moments are recomputed in its bootstrap resamples; they are
never used as the primary frozen-source normalization.

For random-score specificity, each of the existing 500 candidate quartets gets
one fixed random permutation of the four weight magnitudes and one independent
random sign per head, generated by NumPy `default_rng(2026102721)`. Head order,
signed weights, and candidate-bank SHA256 are saved before scoring. Comparison
on the primary normalization requires source moments for every candidate head.
If those moments cannot be recovered, primary random-score specificity is
reported unavailable. No random candidates are selected or replaced using
STAGES cognition. No extra target-normalized random-score family is introduced.

## Outcomes and analysis populations

Use the previously validated task manifests and the same 590 EEG-eligible
participants. The composite requires both validated PCET accuracy2 and validated
face-memory correct responses (expected n=588, verified from the manifests).
Vigilance is excluded from the primary composite and evaluated separately.

Regress each task by unpenalized OLS on an intercept, sex, education (including
the supplied unknown/missing category), center indicators, and the original
age basis: scikit-learn `SplineTransformer(n_knots=4, degree=3,
knots='quantile', include_bias=False, extrapolation='linear')`. This is the
same spline as the main analysis. The existing demographic preprocessing is
used: median imputation with a missingness indicator for sex, median age
imputation, education one-hot encoding, and predictor standardization.
Center is included as three indicators with Geisinger as reference. OLS uses
the minimum-norm solution if a resample loses a covariate category.

Fit outcome adjustment on all participants in the relevant analysis population,
independently of all EEG scores. Standardize each task's residuals using
population SD (ddof=0), average the two standardized residuals, and standardize
that average again. A composite <=-1.0 defines low performance. Domain outcomes
use their individual standardized residuals and the same -1.0 cutoff. These
are concurrent task-performance outcomes, not adjudicated clinical diagnoses.
Report realized counts rather than assuming a normal 16% case rate.

## Inference

Draw 2,000 participant resamples independently within each of the four centers,
preserving each center's sample size. Each draw refits demographic preprocessing,
age spline, OLS adjustment, residual scaling, composite scaling, and case labels;
it then rebuilds the within-center age pairs. The primary EEG score retains its
original source constants. Paired score comparisons use the same draws.
Report percentile 95% intervals and requested/valid replicate counts.

If a center has no eligible case/noncase pairs, its estimate is unavailable.
The pooled endpoint uses all eligible pairs from the other centers. Equal-center
weighting requires an estimate for all four centers; it is unavailable otherwise.
The same rule applies in each bootstrap draw. Nonfinite replicates are omitted
only for that metric and their count is reported; no threshold or center is
changed to make an interval estimable. Participants and eligible pairs are not
treated as independent observations. These intervals condition on four observed
center families and do not sample a population of new centers.

For the one-sided test, perform 10,000 label permutations within center, keeping
ages, scores, and each center's case count fixed. Rebuild case/noncase eligible
pairs after each permutation. Monte Carlo p=(1 + number of null AUROCs >=
observed AUROC)/(10,000+1). This test assumes exchangeability of the adjusted
case labels within each center. Record deterministic seeds in code.

## Complete set of eight exploratory analysis families

All are exploratory, unadjusted for multiplicity, and reported regardless of
direction. Items dependent on missing source moments are labeled unavailable.

1. **Continuous concordance:** same-center pairs within two years whose
   composite values differ by >=0.25 SD; concordance means higher risk for lower
   cognition. Give half credit for tied scores.
2. **Brain-health comparator:** negated BHS on the primary outcome and paired
   Stable4-minus-BHS AUROC, using shared bootstrap samples.
3. **Random-score specificity:** Stable4's percentile among the 500 fixed random
   scores, plus the proportion at or above its primary AUROC. Report ties and
   the exact percentile convention (100 times [number strictly below + half
   the number equal]/500). Requires the matching frozen source scales.
4. **Threshold sensitivity:** composite <=-1.5 and <=-0.5 SD.
5. **Domain outcomes:** PCET, face memory, and vigilance separately, each with
   the same adjustment and <=-1.0 SD cutoff, using its validated manifest.
6. **Normalization sensitivity:** within-center STAGES population means/SDs for
   the four heads instead of original Challenge moments, fixed signed weights.
7. **Equal-center weighting:** arithmetic mean of all four center-specific
   AUROCs alongside the pair-pooled estimate, subject to estimability above.
8. **Pipeline check:** fixed model head `pred_regression_f_ahi` against observed
   AHI >=15 events/hour using identical within-center age-pair rules (expected
   n=572). Higher model AHI indicates higher risk. This does not establish that
   the supplied observed AHI was measured during the indexed PSG. Preserve the
   earlier MAE check in the Supplement as a prior result.

Available-only execution reports the BHS comparator, normalization sensitivity,
threshold/domain variants of available scores, continuous concordance,
equal-center summaries, and AHI check. This does not complete the missing
frozen-source comparisons or random-score specificity.

## Power stage before primary evaluation

The proposed power percentages (including 76% at AUROC 0.60) were supplied as
planning approximations and have not been verified. Do not print them as study
results. After computing score-free outcome labels and pair counts, simulate
1,000 scenarios each for true AUROC 0.55, 0.58, 0.60, 0.62, and 0.65 at the
realized -1.0 and -1.5 thresholds. Retain observed ages/centers and case counts;
generate independent participant normal errors plus binormal shift
sqrt(2)*Phi^-1(AUROC) for cases. Estimate rejection probability for a two-sided
95% procedure accounting for reused participants in pairs. Freeze the exact
simulation and inference implementation before looking at the primary score.
The primary CLI remains locked until this design-dependent stage is complete.
Report simulation uncertainty and distinguish conditional fixed-label power
from power of the complete outcome-adjustment process.

## Joint presentation and interpretation fixed before rank results

Show organizer-scored I0004 validation 0.723 and I0007 test 0.622 as prior
diagnosis-task results, alongside new STAGES pooled and center estimates and
the BHS comparator. Do not pool across settings. If organizer case/control
counts and resampling information cannot be recovered, plot those prior points
without intervals and state that in the caption; AUROC alone does not supply
an interval. Site-code differences alone do not establish person-level
independence from backbone/head training. Preserve the existing overlap audit.

Interpretation for the primary frozen-source endpoint:

* **Lower bound >0.5:** "The fixed Stable4 score, specified on Human Sleep
  Project data, also ranked sleep-clinic patients with low concurrent cognitive
  performance above age-matched peers, consistent with the organizer-scored
  hidden-site results."
* **Point >0.5, interval includes 0.5:** "The STAGES estimate was in the same
  direction as the hidden-site results but was not statistically distinguishable
  from chance."
* **Point <=0.5:** "The fixed score's discrimination of later diagnoses at
  hidden sites did not extend to concurrent cognitive performance in a younger
  sleep-clinic population."

These sentences cannot be used to describe a replacement-normalized score as
the primary frozen-source result. If the original artifact remains unavailable,
state that the primary endpoint could not be computed as specified. The prior
small, imprecise BHS association and absent Stable4 MAE gain motivated this
analysis; rank results do not retrospectively change that chronology.
